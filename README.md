# 🗺️ Парсер компаний с Яндекс.Карт

Скрипт для автоматического сбора данных о компаниях с Яндекс.Карт.

## 📋 Что собирает

| Поле | Описание |
|------|----------|
| Название | Наименование компании |
| Адрес | Юридический/фактический адрес |
| Телефон | Контактный номер |
| Email | Электронная почта |
| Сайт | Ссылка на сайт компании |
| Руководитель | ФИО и должность |

## 🛠️ Технологии

- **Python 3**
- **Selenium** — автоматизация браузера
- **openpyxl** — сохранение в Excel
- **webdriver-manager** — автоустановка драйвера Chrome

## ⚙️ Как работает

1. Открывает Яндекс.Карты
2. Ищет компании по запросу (регион + тип деятельности)
3. Собирает ссылки на карточки с прокруткой
4. Заходит в каждую карточку и извлекает данные
5. Проверяет дубликаты по названию
6. Сохраняет результат в Excel с форматированием

## ✨ Особенности

- Обход автоматизации (эмуляция человека, случайные User-Agent)
- Проверка дубликатов — не собирает одну компанию дважды
- Форматирование Excel: цвета, границы, ширины колонок
- Обработка ошибок: скрипт не падает при сбое на одной карточке
